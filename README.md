# XiHunJi Digital Wedding Invitation

XiHunJi（喜婚记）电子请柬 is a mobile-first digital wedding invitation experience for couples and guests.

The single-page app includes invitation customization, a shareable guest view, wedding details and countdown, RSVP collection, dietary preferences, and guest seating management.

## Run locally

Open `index.html` in a modern web browser. No build step is required.

## Notes

This version stores prototype data in the browser. A production deployment should connect RSVP submissions and shared invitation data to a hosted database.
